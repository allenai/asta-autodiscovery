Output / script truncationopen
The agent conversation balloons past 1M tokens, history is trimmed to ~61k, and scripts get cut mid-line → incomplete/invalid code → reviewer rejects. The single biggest driver in the first round.
Generated-code bugs
Buggy analysis the reviser can't fix: TypeError (e.g. GEE.from_formula() got multiple values for 'groups'), ValueError, KeyError / "not in index", AttributeError, SyntaxError.
Statistical non-convergence
The model won't fit: Singular matrix, "did not converge", PerfectSeparation.
Missing data / infeasible test
Dataset lacks a required column or mapping (no Shipping pathway; no culture→country map) → forced substitution or abort.
Hypothesis not supportednot a bug
The experiment ran fine but the reviewer rejects on the merits — p≥0.05, effect too small, wrong direction. A legitimate low-surprise outcome that still scores 0.

The 8 GPUs sit idle for ~98% of every step while the reward server runs the 64 experiments — the run is entirely reward-bound. Generation (SGLang) is a small slice at the front of the reward phase; the actual gradient step is under a minute.
