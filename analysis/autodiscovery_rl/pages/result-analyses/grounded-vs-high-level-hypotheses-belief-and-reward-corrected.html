Grounding hypotheses is roughly reward-neutral

Re-run with a corrected classifier that calls a hypothesis "grounded" only when it writes variables in schema/identifier form (backticks, snake_case, quoted category values, coded levels) rather than merely mentioning a word that happens to be a column. The earlier "+0.06–0.08, unanimous" reward advantage for grounded hypotheses was largely an artifact of the old over-inclusive matcher. Corrected, the reward gap is ~0 in the baseline and a small +0.02 in colsfix (mostly fmt3).

What changed. The old matcher tagged a hypothesis "grounded" if it contained any word matching a column name — but many columns are plain English (gender, age, income, bmi), so prose hypotheses got miscounted as grounded. That inflated the grounded group to 72% and manufactured a reward gap. The corrected classifier requires an actual schema token; the split is now a balanced ~50/50 and the gap collapses.

Takeaways

  • The strong grounded→reward effect was a classifier artifact. A proper schema-token classifier erases it in the baseline (−0.001, 9/20) and shrinks it to +0.02 in colsfix.
  • Grounding is essentially reward-neutral — consistent with the earlier finding that column-guessing is orthogonal to reward. Priors and belief shifts are nearly identical across tiers (prior ~0.62 both; shift within 0.01–0.015).
  • The only residual signal is fmt3 in colsfix (+0.057). It does not replicate in the baseline fmt3 (−0.003), so treat it as suggestive, not established.
  • Methods lesson: "mentions a column" is not "grounded" when column names are common English words. Require the model to write the variable in schema/identifier form.

Classifier confidence (hybrid audit). The regex does the full pass; on a 120-rollout random audit, gpt-5-mini (few-shot on the same definition) is 75% concordant overall — 87% on grounded, 63% on NL. Disagreements are almost all borderline conceptual references (regex NL → gpt grounded), plus a couple of real regex misses (all-caps / multi-value parentheticals like (INCOME), (Pan, Pongo, Papio)). The NL/grounded boundary is genuinely fuzzy (~25% debatable), but the reward gap is ~0 under either labeling, so the conclusion is robust to it.
Caveat. Still correlational and observational (not a matched-pair intervention). But the direction is now clear: under a defensible definition of "grounded", there is no reliable reward advantage. The paired de-grounding experiment (hyp100) would be the causal test — its naturalized hypotheses mostly failed execution, which is itself evidence that grounding matters for runnability, if not for scored reward.
