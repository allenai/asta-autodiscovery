Sanity runs — reward, response length and entropy per step

Every 1-sample sanity run, one row each. rew = rollout/raw_reward (true mean reward; for binary rewards it is the fraction of the group that scored 1). len = rollout/response_lengths in tokens. ent = train/entropy_loss. min = wall-clock minutes since the previous step (step 1 is blank; the step-1→2 interval also carries the step-0 eval and startup, so it usually overstates). Values are parsed from each experiment's Beaker logs; for runs that were preempted and restarted, the job that reached the most steps is used. A dot means the run never reached that step.
