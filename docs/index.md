# Asta AutoDiscovery

New here? This is the technical documentation for 
[https://github.com/allenai/asta-autodiscovery](https://github.com/allenai/asta-autodiscovery)
which is the software behind [autodiscovery.allen.ai](https://autodiscovery.allen.ai/) 

To get started working with the stack, see [Quick start](quickstart.md): choose a model provider,
write a two-line `.env`, and run the stack with `make dev`.
